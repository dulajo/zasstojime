# ADR-0036: Krátké spoje: maximum z dostupných snímků

- **Stav:** Nahrazeno ADR-0039
- **Oblast:** Metodika
- **Datum:** 2026-10-02

## Kontext

S pravidlem 3 snímků (ADR-0005) by krátké spoje měly maximum `NULL`.

## Rozhodnutí

Při < 3 snímcích maximum = minimum z dostupných.

## Důsledky

- Odpadlo s ADR-0039.
