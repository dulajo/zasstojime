# ADR-0012: Na webu „součet zpoždění spojů“, ne „čas cestujících“

- **Stav:** Přijato
- **Oblast:** Komunikace
- **Datum:** 2026-10-02

## Kontext

Neznáme obsazenost vozidel, takže nemůžeme tvrdit, kolik času ztratili cestující.

## Rozhodnutí

Souhrnné číslo se popisuje jako součet zpoždění spojů. U „Moje trasa“ jako „kdybys jel tímto spojem každý den“.

## Důsledky

- Omezuje virální formulace, ale chrání věrohodnost.
