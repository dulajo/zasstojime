# ADR-0006: Index dochvilnosti ze zpoždění na konečné

- **Stav:** Nahrazeno ADR-0033
- **Oblast:** Metodika
- **Datum:** 2026-10-02

## Kontext

Původní návrh indexu dochvilnosti.

## Rozhodnutí

Index = podíl dokončených spojů se zpožděním na konečné < 180 s.

## Důsledky

- Nespravedlivé k cestujícím na trase (vyrovnávací čas před konečnou). Viz ADR-0033.
