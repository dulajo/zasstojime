# ADR-0023: Klient: Next.js + TypeScript

- **Stav:** Přijato
- **Oblast:** Technologie
- **Datum:** 2026-10-02

## Kontext

Autor chce typový, současný frontend, ne Kotlin.

## Rozhodnutí

Next.js (App Router), TypeScript strict, Tailwind, TanStack Query.

## Zvažované alternativy

| Alternativa | Proč ne |
|---|---|
| Kotlin/JS, Compose for Web | Slabé SEO a generování OG obrázků. |
