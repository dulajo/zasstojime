# ADR-0027: Frontend hostovaný na Cloudflare

- **Stav:** Přijato
- **Oblast:** Provoz
- **Datum:** 2026-10-02

## Kontext

Virální provoz má jít mimo homelab; možná monetizace.

## Rozhodnutí

Frontend na Cloudflare (Workers/Pages).

## Zvažované alternativy

| Alternativa | Proč ne |
|---|---|
| Vercel | Bezplatný tarif zakazuje komerční použití. |
