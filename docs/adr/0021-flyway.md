# ADR-0021: Migrace: Flyway

- **Stav:** Přijato
- **Oblast:** Technologie
- **Datum:** 2026-10-02

## Kontext

Autor zná Liquibase a chce poznat Flyway.

## Rozhodnutí

Flyway, verzované SQL soubory `db/migration/V{n}__{popis}.sql`.

## Zvažované alternativy

| Alternativa | Proč ne |
|---|---|
| Liquibase | Známý, ale cílem je naučit se Flyway. |
